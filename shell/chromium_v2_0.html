What is computed, and what is input

Computed live, from the matrices

The eight Gell–Mann matrices are built at load. Everything below is then derived by actual matrix algebra in JS — no constant is hardcoded:

TF from Tr(TaTb) = TFδab
CF from ∑a TaTa = CF𝕀
fabc from [Ta,Tb] = i fabcTc
CA from facdfbcd = CAδab

The residuals are displayed beside the values. Path III: target and result are never the same line.

Input, not derived

αs(MZ) = 0.1180 is a measured world-average input, not a prediction. MZ = 91.1876 GeV likewise. ΛQCD is then derived from them by inverting the 1-loop solution — so Λ is a consequence of the measurement, not an independent result.

Nothing in this sim predicts αs. It shows how it runs once you fix it at one scale.

Loop order

1-loop: αs(Q) = 4π / (β0 ln(Q²/Λ²)).
2-loop adds the β1 ln-ln term. Both are drawn; the gap between them is the honest size of the truncation error, and it grows as Q falls.

Where it breaks

Below ~1 GeV perturbation theory is not valid. The curve is drawn into that region so you can see it diverge, but the divergence is the approximation failing, not a physical infinity. Confinement is real; the pole is an artefact. The greyed zone marks it.

The join

M₃(C) appears in all three sims and it is the same object:

PLATEAUM — a node on the subalgebra chain (real dim 19, Dirac dim 128; with C or H added it drops to the 16 plateau).
CHROMIUM — its traceless anti-hermitian part is su(3): 8 generators, 8 gluons, CA = 3.
LAGRANGIUM — sector 1, where CA ≠ 0 produces the fabc three- and four-gluon vertices.

That chain is arithmetic, not analogy: CA = N = 3 is why gluons couple to gluons, which is the sign of β0, which is asymptotic freedom.

The benchmark

"Push" measures real 3×3 complex matrix multiplications per second in this tab — the same operation used to derive CF. It is a measurement of your browser on your machine, taken now. It is not a claim about anything else.
