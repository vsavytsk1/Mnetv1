Θέμα Α

Θεωρία · theory · 25 μονάδες
The smallest polyhedral graph, and self-dual. The paper opens with the smallest theorem it owns.
Α1Μονάδες 6 · 6 marks

Έστω μια συνάρτηση f ορισμένη σε ένα διάστημα Δ. Αν

  • η f είναι συνεχής στο Δ και
  • f′(x) = 0 για κάθε εσωτερικό σημείο x του Δ,

να αποδείξετε ότι η f είναι σταθερή σε όλο το διάστημα Δ.

Let f be a function defined on an interval Δ. If

  • f is continuous on Δ, and
  • f′(x) = 0 for every interior point x of Δ,

prove that f is constant on the whole interval Δ.

λύση · answer
Take any x1 < x2 in Δ. f is continuous on [x1, x2] and differentiable on (x1, x2), so the Mean Value Theorem gives a ξ with f(x2) − f(x1) = f′(ξ)(x2 − x1) = 0. Hence f(x1) = f(x2): f is constant on Δ.
Two pyramids pressed base to base. A squeeze.
Α2Μονάδες 5 · 5 marks

Να διατυπώσετε το κριτήριο παρεμβολής.

State the squeeze theorem.

λύση · answer
If h(x) ≤ f(x) ≤ g(x) for all x near x0 (x ≠ x0) and limx→x₀ h(x) = limx→x₀ g(x) = ℓ, then limx→x₀ f(x) = ℓ.
Dual of the octahedron: swap vertices and faces. An antiderivative undoes a derivative the same way.
Α3Μονάδες 4 · 4 marks

Έστω f μια συνάρτηση ορισμένη σε ένα διάστημα Δ. Τι ονομάζεται αρχική συνάρτηση ή παράγουσα της f στο Δ;

Let f be a function defined on an interval Δ. What is called an antiderivative (primitive) of f on Δ?

λύση · answer
Any function F that is differentiable on Δ with F′(x) = f(x) for every x ∈ Δ.
Five statements, one five-fold axis. Σωστό on top, Λάθος underneath.
Α4Μονάδες 10 · 10 marks

Να χαρακτηρίσετε τις προτάσεις που ακολουθούν γράφοντας στο τετράδιό σας, δίπλα στο γράμμα που αντιστοιχεί σε κάθε πρόταση, τη λέξη Σωστό, αν η πρόταση είναι σωστή, ή Λάθος, αν η πρόταση είναι λανθασμένη.

  • α) Μια συνάρτηση f : ℝ → ℝ είναι “1-1”, αν και μόνο αν υπάρχουν διαφορετικά σημεία της γραφικής της παράστασης με την ίδια τεταγμένη.
  • β) Αν μια συνάρτηση f είναι παραγωγίσιμη σε ένα σημείο x0 του πεδίου ορισμού της, τότε είναι και συνεχής στο σημείο αυτό.
  • γ) Έστω μια συνάρτηση f συνεχής σε ένα διάστημα Δ και δύο φορές παραγωγίσιμη στο εσωτερικό του Δ. Αν f″(x) > 0 για κάθε εσωτερικό σημείο x του Δ, τότε η f είναι κυρτή στο Δ.
  • δ) Αν η συνάρτηση g είναι παραγωγίσιμη στο x0 και η συνάρτηση f είναι παραγωγίσιμη στο g(x0), τότε η συνάρτηση f∘g είναι παραγωγίσιμη στο x0 και ισχύει (f∘g)′(x0) = f′(g(x0)) · g′(x0).
  • ε) Η συνάρτηση f(x) = σφx είναι παραγωγίσιμη στο ℝ − {x | ημx = 0} και ισχύει (σφx)′ = 1ημ²x.

Mark each of the following statements as True (Σωστό) or False (Λάθος).

  • a) A function f : ℝ → ℝ is “1-1” if and only if there exist distinct points of its graph with the same y-coordinate.
  • b) If a function f is differentiable at a point x0 of its domain, then it is also continuous at that point.
  • c) Let f be continuous on an interval Δ and twice differentiable in the interior of Δ. If f″(x) > 0 for every interior point x of Δ, then f is convex on Δ.
  • d) If g is differentiable at x0 and f is differentiable at g(x0), then f∘g is differentiable at x0 and (f∘g)′(x0) = f′(g(x0)) · g′(x0).
  • e) The function f(x) = cot x is differentiable on ℝ − {x | sin x = 0} and (cot x)′ = 1sin²x.
λύση · answer
α Λάθος · β Σωστό · γ Σωστό · δ Σωστό · ε Λάθος. (a) is the definition turned inside out; (e) is missing a sign — (σφx)′ = −1/ημ²x.

Β1Μονάδες 8 · 8 marks

Να προσδιορίσετε τη συνάρτηση h = f∘g.

Determine the function h = f∘g.

λύση · answer
Domain: x ≥ 2 and g(x) > 1 ⇔ √(x − 2) > 0 ⇔ x > 2. There h(x) = 2 ln(√(x − 2)) = ln(x − 2). h(x) = ln(x − 2), x ∈ (2, +∞).

Στα επόμενα ερωτήματα να θεωρήσετε ότι h(x) = ln(x − 2), x ∈ (2, +∞).

In the following questions take h(x) = ln(x − 2), x ∈ (2, +∞).

The icosahedron’s dual — V and F trade places, E stays. h⁻¹ trades x and y the same way.
Β2Μονάδες 9 · 9 marks

Να αποδείξετε ότι η συνάρτηση h αντιστρέφεται (μονάδες 3) και να προσδιορίσετε τη συνάρτηση h−1 (μονάδες 6).

Prove that h is invertible (3 marks) and determine the function h−1 (6 marks).

λύση · answer
ln is 1-1, so h(x1) = h(x2) ⇒ x1 = x2: h is invertible. It is continuous and strictly increasing with limits −∞ (at 2⁺) and +∞, so its range is ℝ. y = ln(x − 2) ⇔ x = ey + 2. h−1(x) = ex + 2, x ∈ ℝ.
Triangles meet squares at every vertex. Two factors meet in a product, and −∞ wins.
Β3Μονάδες 8 · 8 marks

Να υπολογίσετε το όριο limx→2 ( h(x) · f(x)x − 2 ).

Evaluate the limit limx→2 ( h(x) · f(x)x − 2 ).

λύση · answer
The expression only exists for x > 2. f(2) = 0, so f(x)/(x − 2) = (f(x) − f(2))/(x − 2) → f′(2) = 2, while h(x) = ln(x − 2) → −∞. Product: −∞. (Derivative definition, not L’Hôpital — that rule is outside the syllabus.)

Θέμα Γ

Μονοτονία · σύνολο τιμών · ολοκληρώματα · monotonicity, range, integrals · 25 μονάδες

Δίνεται η συνάρτηση f : ℝ → ℝ με τύπο f(x) = κx³ + μxx² + 1 με κ, μ ∈ ℝ, για την οποία ισχύουν τα ακόλουθα:

  • Η f έχει οριζόντια ασύμπτωτη στο +∞.
  • Η ευθεία y = x εφάπτεται στη γραφική παράσταση της f στην αρχή των αξόνων.

Given the function f : ℝ → ℝ with f(x) = κx³ + μxx² + 1, κ, μ ∈ ℝ, such that:

  • f has a horizontal asymptote at +∞;
  • the line y = x is tangent to the graph of f at the origin.
Truncation cuts the corners and keeps the shape. Two conditions cut two parameters: κ = 0, μ = 1.
Γ1Μονάδες 8 · 8 marks

Να αποδείξετε ότι: i) κ = 0 και ii) μ = 1.

Prove that: i) κ = 0 and ii) μ = 1.

λύση · answer
If κ ≠ 0 then f(x) behaves like κx at +∞ and runs off to ±∞ — no horizontal asymptote — so κ = 0. Then f(x) = μx/(x² + 1), f(0) = 0 and f′(0) = μ; the tangent at the origin is y = μx, which must be y = x, so μ = 1. Hence f(x) = x/(x² + 1).
Monotone in three pieces, no gaps in the range. This solid tiles all of space with no gaps either.
Γ2Μονάδες 11 · 11 marks

i) Να μελετήσετε τη συνάρτηση f ως προς τη μονοτονία και τα ακρότατα (μονάδες 6).

ii) Να αποδείξετε ότι το σύνολο τιμών της f είναι το [ −12, 12 ] (μονάδες 3) και να βρείτε το πλήθος των ριζών της εξίσωσης f(x) = 12 + α², για κάθε τιμή της παραμέτρου α ∈ ℝ (μονάδες 2).

i) Study f for monotonicity and extrema (6 marks).

ii) Prove that the range of f is [ −12, 12 ] (3 marks) and find the number of roots of the equation f(x) = 12 + α² for every value of the parameter α ∈ ℝ (2 marks).

λύση · answer
f′(x) = (1 − x²)/(x² + 1)²: decreasing on (−∞, −1], increasing on [−1, 1], decreasing on [1, +∞); min f(−1) = −½, max f(1) = ½. With f → 0 at ±∞ the range is [−½, ½]. The right-hand side ½ + α² is ≥ ½ = max f: α = 0 → exactly one root, x = 1; α ≠ 0 → no roots.
Eight triangles, eighteen squares, and one clean relation between neighbours — like Iν and Iν+1.
Γ3Μονάδες 6 · 6 marks

Για ν ∈ ℕ ορίζουμε Iν = ∫01 x2ν+1x² + 1 dx.

i) Να αποδείξετε ότι Iν + Iν+1 = 12ν + 2, ν ∈ ℕ.

ii) Να υπολογίσετε τα I0, I1 και I2.

For ν ∈ ℕ define Iν = ∫01 x2ν+1x² + 1 dx.

i) Prove that Iν + Iν+1 = 12ν + 2, ν ∈ ℕ.

ii) Compute I0, I1 and I2.

λύση · answer
Iν + Iν+1 = ∫₀¹ x2ν+1(1 + x²)/(x² + 1) dx = ∫₀¹ x2ν+1 dx = 1/(2ν + 2). Then I0 = ½ ln(x² + 1)|₀¹ = ½ ln 2, I1 = ½ − I0 = (1 − ln 2)/2, I2 = ¼ − I1 = (2 ln 2 − 1)/4.

  • 0 < g(x) < 1 for every x ∈ ℝ,

Thirty vertices, each the midpoint of an icosahedron edge — a point sitting exactly between two ends, which is where Bolzano finds a root.
Δ1Μονάδες 6 · 6 marks

Να αποδείξετε ότι υπάρχει μοναδικό x1 ∈ (−1, 0) ώστε: g(x1) + x1 = 0.

Prove that there exists a unique x1 ∈ (−1, 0) such that g(x1) + x1 = 0.

λύση · answer
φ(x) = g(x) + x is continuous with φ(−1) = g(−1) − 1 < 0 and φ(0) = g(0) > 0, so Bolzano gives x1 ∈ (−1, 0). φ′ = g′ + 1 is continuous and never zero, so it keeps one sign on ℝ: φ is strictly monotone, hence 1-1, and the root is unique. (That “continuous derivative” clause in the setup exists for exactly this line.)

Δίνεται επιπλέον η παραγωγίσιμη συνάρτηση f(x) = x²(g(x) + x),x ∈ (−∞, 0)2ημx + εφx − κx,x ∈ [0, π2) με κ ∈ ℝ.

Also given is the differentiable function f(x) = x²(g(x) + x),x ∈ (−∞, 0)2 sin x + tan x − κx,x ∈ [0, π2) with κ ∈ ℝ.

κ = 3, so a three-fold axis; two marks, so the smallest spini on the page.
Δ2Μονάδες 2 · 2 marks

Να αποδείξετε ότι κ = 3.

Prove that κ = 3.

λύση · answer
f is differentiable at 0 and f(0) = 0. Left: (f(x) − f(0))/x = x(g(x) + x) → 0. Right: (2ημx + εφx − κx)/x → 2 + 1 − κ (since ημx/x → 1 and εφx/x → 1). Equal one-sided derivatives ⇒ 3 − κ = 0 ⇒ κ = 3.
The famous graph for the famous question.
Δ3Μονάδες 7 · 7 marks

Να αποδείξετε ότι στο διάστημα [0, π2) ισχύουν:

i) f(x) ≥ 0 και (μονάδες 4)

ii) η εξίσωση 3f(x) = π έχει ακριβώς μια ρίζα, x2. (μονάδες 3)

Prove that on the interval [0, π2):

i) f(x) ≥ 0, and (4 marks)

ii) the equation 3f(x) = π has exactly one root, x2. (3 marks)

λύση · answer
With t = συνx ∈ (0, 1]: f′(x) = 2t + 1/t² − 3 = (t − 1)²(2t + 1)/t² ≥ 0, zero only at x = 0, so f is strictly increasing and f(x) ≥ f(0) = 0. Since f(0) = 0 and f → +∞ as x → π/2⁻ (εφx blows up), f([0, π/2)) = [0, +∞) ∋ π/3; strict monotonicity makes x2 unique.
C60’s twin: identical V, E, F — a different solid with the very same count. Two regions, equal areas.
Δ4Μονάδες 10 · 10 marks

i) Να αποδείξετε ότι f(x) ≥ 0 στο διάστημα [x1, 0]. (μονάδες 3)

ii) Έστω Ω το χωρίο που περικλείεται από τη γραφική παράσταση της συνάρτησης f, τον άξονα x′x και τις ευθείες x = x1 και x = f(x2), όπου x1 είναι ο αριθμός από το ερώτημα Δ1 και x2 είναι η ρίζα από το ερώτημα Δ3ii. Αν ο άξονας y′y χωρίζει το Ω σε δύο ισεμβαδικά χωρία, να αποδείξετε ότι:

∫x₁0 x³ g′(x) dx = x1⁴4 + π²2 − 3 ln2 − 3. (μονάδες 7)

i) Prove that f(x) ≥ 0 on the interval [x1, 0]. (3 marks)

ii) Let Ω be the region enclosed by the graph of f, the x-axis and the lines x = x1 and x = f(x2), where x1 is the number from Δ1 and x2 the root from Δ3ii. If the y-axis divides Ω into two regions of equal area, prove that:

∫x₁0 x³ g′(x) dx = x1⁴4 + π²2 − 3 ln2 − 3. (7 marks)

λύση · answer
On [x1, 0]: f = x²·φ(x) with φ increasing and φ(x1) = 0, so f ≥ 0. f(x2) = π/3. Right area: E2 = ∫₀π/3(2ημx + εφx − 3x) dx = 1 + ln2 − π²/6. Left area, integrating x²g(x) by parts and using g(x1) = −x1: E1 = x1⁴/12 − J/3, where J = ∫x₁0 x³g′(x) dx. Setting E1 = E2 and solving: J = x1⁴/4 + π²/2 − 3 ln2 − 3.
