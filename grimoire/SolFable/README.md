receipts and frozen artifacts from a conversation between three parties, and

kernels, the receipts, the frozen HTML previews.

## A LIVE PAGE WAS SERVING CORRUPTED GLYPHS, and is not any more

`01.SolFableTOv3/Thea_v3.0_preview.html` is also published (`IO_PAGES.md` line
27). It differed from the top-level copy, and the difference was rot:

```text
  clean       166,537 B   12:25   0 x U+FFFD
  corrupted   166,549 B   11:52   6 x U+FFFD, baked into the bytes
```

Two lines, both an em-dash:

```text
  line   7   <title>THEA v3.0 — LIGHT MATRIX</title>
             <title>THEA v3.0 ��� LIGHT MATRIX</title>
  line 236   <h1 class="title">THEA v3.0 — LIGHT MATRIX</h1>
```

The arithmetic names the mechanism exactly: two 3-byte em-dashes (`E2 80 94`)
were each decoded byte-by-byte and replaced by three 3-byte `U+FFFD`
(`EF BF BD`), so 6 replacements at +2 bytes each = **the 12-byte difference,
to the byte**. Nothing else in 2,062 lines differed.

Healed by copying the clean bytes over it. The published page now carries zero
replacement characters. **Curse 25 -- Rune Rot:** a fumbled decode carves
garbage into something sacred, silently, and the only witness is somebody
reading the glyph.
