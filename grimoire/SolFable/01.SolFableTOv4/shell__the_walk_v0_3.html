The running graph — the same graph, its stability edge

computed The walker above measures diffusion by wandering. This panel measures the same diffusion run as a solver: it relaxes a potential on the contact graph by the explicit step x ← x − λ(Lx − b), where L is the graph Laplacian and b is a unit charge placed on one doorway minus its mean (so it has a solution). The residual ‖Lx − b‖ is the receipt; drive it to the floor and you have solved the cage's Green's function — the temperature field from heating one door.
measured live An explicit step of size λ is stable only while λ < 2/λ_max. We power-iterate λ_max on this exact graph and express the knob as a fraction of that edge, f = λ·λ_max/2. Below f = 1 the residual falls (green); at f = 1 it crawls the edge (gold); past it, the top mode grows and the residual escapes (red). The fastest stable step is f_opt = λ_max/(λ₂ + λ_max), the classic optimal Richardson parameter — read off live from the residual's own decay rate. Because these cages are stiff (λ_max ≫ λ₂), the fastest step sits almost on the edge: the price of speed is a razor.
honest boundary · Path III The settled badge lights only while the residual holds below tolerance for several frames. Target (f = 1), current f, and err = |f − 1| are shown side by side, and the target is never printed as the result (Curse 26 — the trap FSlimium's original graph fell into). The cave sigil λ = 0.1473 is a reference line, not a verdict; whether it lands inside or outside this graph's edge is a fact about the graph, measured, not assumed.
